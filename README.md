# Tech Stack

* HTML5 Canvas — Game rendering with pixel-perfect scaling
* Vanilla CSS — All retro visuals (no images, no external assets)
* Vanilla JavaScript — Game loop, collision, particles, input handling

# Project Structure

snake-84/
└── snake.html          # That's it. Everything is in here.\

# Scoring

* +10 points per food pellet
* Speed increases by ~2ms every pellet
* Maximum speed cap at 55ms (good luck)
